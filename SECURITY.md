# Security reporting

Use **Report a vulnerability** in this repository's GitHub Security tab
if private vulnerability reporting is available. Otherwise, ask the
maintainer for a private contact channel and omit all vulnerability details
from the public request. Include the affected version, impact, and
reproduction steps with synthetic data in the private report.

Keep Stripe secrets, customer information, raw webhook bodies and database
snapshots out of public reports. Rotate exposed credentials through Stripe
or your hosting provider.
