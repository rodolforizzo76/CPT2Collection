# Contributing

Use the public issue tracker for feature requests and reproducible bugs.
Include CPT2Collection, WordPress, PHP and database versions, the observed
result, the expected result, and a reproduction using synthetic data.
Omit customer records, credentials, raw payment payloads and database dumps.

Keep changes focused. For changes affecting commerce, describe the effect
on existing data, retries, and concurrent operations. Include the checks
you ran and their results. See [Build and test](docs/development.md) and
[Localization](docs/localization.md). Use [private reporting](SECURITY.md)
for security issues.
